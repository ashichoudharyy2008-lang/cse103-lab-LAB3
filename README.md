## Overview

This repository contains lab work for **LAB 3** of the Computer Fundamentals & Career Pathways (CSE103) course at **K.R. Mangalam University, Gurugram**.

The repository demonstrates basic Git and GitHub workflows, Python programming, version control, and Markdown documentation.

## How to Run

Clone the repository:

```bash
git clone https://github.com/ashichoudharyy2008-lang/cse103-lab-LAB3.git
```

Navigate into the folder:

```bash
cd cse103-lab-LAB3
```

Run the Python program:

```bash
python3 main.py
```
